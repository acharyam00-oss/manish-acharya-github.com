MANISH ACHARYA — PORTFOLIO WEBSITE

Files:
- index.html — complete responsive website
- assets/portfolio-page-1.jpg ... portfolio-page-8.jpg — rendered portfolio pages
- assets/Manish_Acharya_Portfolio.pdf — original portfolio PDF

LOCAL PREVIEW:
Open index.html in a browser.

GITHUB PAGES:
1. Create a GitHub repository.
2. Upload index.html and the assets folder.
3. Repository Settings -> Pages.
4. Select the main branch/root folder and save.
5. GitHub will provide the public website URL.

NOTES:
- Replace/add project images in assets if you want individual project pages.
- Update the LinkedIn URL or email in index.html if needed.
